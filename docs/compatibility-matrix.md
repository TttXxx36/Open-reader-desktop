## 兼容等级

- **已实现**：有 Rust/前端测试或授权夹具，且远程 CI 通过。
- **可部分导入**：可保存一部分安全字段，但会明确显示未实现能力；不保证端到端执行。
- **明确标记/拒绝**：预览中显示原因，严禁静默丢弃脚本、XPath、认证和音频能力。
- **暂不支持**：不提供导入承诺，进入对应里程碑后再做格式或运行时评估。

## 兼容原则

1. 先定义内部数据模型，再做字段映射；不为兼容而复制不安全行为。
2. 每支持一个字段，必须补充最小测试夹具、错误案例和迁移说明。
3. 网络请求、重定向、响应体、缓存、图片、脚本和请求头均有上限。
4. 真实站点只在用户确认授权、服务条款允许且不绕过访问控制时测试。
5. 兼容性矩阵随每个里程碑更新，并链接到对应 GitHub Actions 运行记录。
