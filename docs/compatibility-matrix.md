# 书源与内容兼容性矩阵

兼容性按“已验证”而不是“理论上可解析”记录。测试内容必须是授权、公开测试或公版内容。

| 类型 | 目标版本 | 状态 | 备注 |
| --- | --- | --- | --- |
| 本地 TXT | MVP | 计划中 | 编码探测、章节识别、书签与进度 |
| 本地 EPUB | MVP | 计划中 | 优先支持标准 EPUB 2/3 文本与目录 |
| Legado 3.0 JSON 基础字段 | M3/M4 | 计划中 | searchUrl、ruleSearch、ruleBookInfo、ruleToc、ruleContent |
| Legado 3.0 CSS/XPath/正则选择器 | M3/M4 | 计划中 | 逐项实现并用夹具测试 |
| Legado JavaScript 书源 | M4 | 评估中 | 需要受限运行时、超时、资源配额和权限模型 |
| 多源搜索与替换规则 | M5 | 计划中 | 去重、排序、替换顺序和可解释日志 |
| PDF/漫画/音频 | MVP 后 | 暂不支持 | 需要独立的布局、缓存或播放方案 |

## 兼容原则

1. 先定义内部数据模型，再做字段映射；不为兼容而复制不安全行为。
2. 每支持一个字段，必须补充最小测试夹具和错误案例。
3. Cookie、脚本、请求头等敏感能力默认拒绝，改为逐项授权。
