## 操作与实际结果

### W-01 启动与书架

- 前置条件：关闭旧实例，启动 0.2.0 便携版。
- 操作：启动程序，观察首页和左侧导航；查看本地书籍与书源书籍分区。
- 实际：启动成功；书架显示 2 本本地 TXT 与 1 本书源书籍，来源区标为 `SOURCE BOOKS`。
- 判定：通过。

### W-02 独立搜索与结果展示

- 操作：进入“搜索”，输入 `诡秘之主`，执行搜索；再输入 `demo` 验证小结果集。
- 实际：搜索工作区独立显示 693/202 条结果；卡片包含书名、作者、来源、加入书架、仅搜索和打开；未显示扫描页数、解析条数或空页统计。
- 判定：通过。
- 观察项：部分来源返回乱码或异常标题（如 `����`、数字标题、字母间空格），应在后续 P1 做编码识别/数据质量降级提示。

### W-03 在线结果点击

- 操作：点击搜索结果主条目、`打开` 和 `仅搜索`，分别用 `(C102)铁星` 与 `DEMO` 结果复测。
- 实际：点击触发了详情/目录链路；规则不匹配时显示 `打开失败：toc 规则 item 失败` 或 `content 规则 content 失败`，并给出“重试并刷新”操作。
- 判定：原 P0“点击无响应”通过；测试源兼容性缺陷记录为 P1。

### W-04 本地阅读、排版和恢复

- 操作：从书架打开 TXT；调整字号/行距控件，滚动到中段，等待保存后直接关闭应用，再启动并重新打开。
- 实际：排版控件可用；数据库读数记录了非零 position，重启后恢复中段位置并显示 `本地导入 · 已读 1%`。
- 判定：通过。
- 测试修正：若先滚动到顶部再关闭，会把位置按 0 保存；该现象是测试动作覆盖保存值，不是恢复缺陷。

### W-05 设置页

- 操作：查看“阅读排版”“主题与界面”“远端阅读”三个设置分组。
- 实际：字号预设、字体、主题、对齐、行距、字间距、版心、边距、段距、缩进、自定义颜色和受限追链配额均可见；追链默认关闭。
- 判定：通过；本轮未修改设置。

### W-06 在线书源导入预览

- 前置条件：书源页使用用户提供的公开 URL。
- 操作：选择“导入书源 JSON / URL”，填入 URL，点击“读取并预览”，不点击确认导入。
- 实际：成功解析 219 个书源：5 个可直接运行、143 个兼容保留、71 个需人工处理；脚本/XPath/模板保留原文但不执行；已保存书源数量未改变。
- 判定：通过；规则兼容性继续按 M7 P1 计划处理。
