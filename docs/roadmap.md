# 开发路线图

路线图按可独立验收的里程碑推进；每个里程碑都应在 Issue、PR 和变更记录中留下证据。

## M0 — 范围与治理

确定许可证、贡献规范和安全报告方式；固化内容合法性、书源权限和隐私边界；评估 Legado 3.0 JSON 兼容目标。

## M1 — 工程骨架

初始化 Tauri v2、Vue 3、TypeScript、Rust、SQLite；建立格式化、测试、CI 和开发文档；完成 Windows/WebView2 检查。

## M2 — 本地阅读 MVP

实现 TXT/EPUB 导入、解析、目录、阅读视图、书架、阅读进度、主题/字体/行距设置和离线缓存。

## M3 — 书源协议

统一搜索、书籍详情、目录、正文数据模型；实现 HTTP 客户端、HTML/JSON 解析、超时/重试与测试夹具。

## M4 — 单书源端到端

实现书源导入、校验、调试日志；已用本机合成授权夹具完成搜索到正文闭环，并加入 SQLite 书源管理、启用/停用和阶段诊断。接入真实站点前仍需单独确认授权与服务条款。

## M5 — 多源与可维护性

实现多源搜索、去重、排序、失败隔离、替换规则、章节更新、缓存淘汰和配置导入/导出。

## M6 — Windows 体验

加入 WebView2 能力检测、快捷键、窗口状态、TTS、通知和自动更新（通过安全评估后）。

## M7 — 发布

完成签名安装包、版本策略、回归测试、隐私说明和首个可供公众试用的预览版。
