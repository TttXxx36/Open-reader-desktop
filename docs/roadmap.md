# 开发路线图

路线图按可独立验收的里程碑推进；每个里程碑都应在 Issue、PR 和变更记录中留下证据。

## M0 — 范围与治理

确定许可证、贡献规范和安全报告方式；固化内容合法性、书源权限和隐私边界；评估 Legado 3.0 JSON 兼容目标。

## M1 — 工程骨架

初始化 Tauri v2、Vue 3、TypeScript、Rust、SQLite；建立格式化、测试、CI 和开发文档；完成 Windows/WebView2 检查。

## M2 — 本地阅读 MVP

实现 TXT/EPUB 导入、解析、目录、阅读视图、书架、阅读进度、主题/字体/行距设置和离线缓存。

## M3 — 书源协议

统一搜索、书籍详情、目录、正文数据模型；实现 HTTP 客户端、HTML/JSON 解析、超时/重试与测试夹具。

## M4 — 单书源端到端

实现书源导入、校验、调试日志；已用本机合成授权夹具完成搜索到正文闭环，并加入 SQLite 书源管理、启用/停用和阶段诊断。接入真实站点前仍需单独确认授权与服务条款。

## M5 — 多源与可维护性

- M5.0：完成启用书源并发搜索、统一结果模型、标题/作者归一化去重和单源失败隔离。
- M5.1：完成搜索结果进入远程详情、目录和章节正文阅读，加入详情/章节 SQLite TTL 缓存与过期清理。
- M5.2：完成书源配置校验后的 JSON 导入/导出，以及远程阅读的手动强制刷新。
- M5.3：完成正文 \`replaceRules\` 顺序替换、规则大小/数量校验，以及缓存容量治理（最多 256 条、payload 总量不超过 32 MiB）。
- M5.4：完成目录指纹、章节差异统计、当前章节保留/索引回退，以及强制刷新失败时的 stale 缓存回退；普通阅读不启动后台轮询。
- M5.5：已完成 permission 元数据、来源安全审计、敏感请求头审计、缓存统计命令、启动清理日志、CSP 与重定向限制。
- M5.6：已加入真实翻开书籍图标、版本/产物严格门禁，以及支持 \`v*\` 标签自动发布安装器、便携 ZIP 和 SHA-256 清单。签名暂缓；安装、升级、卸载和 WebView2 回归仍待执行。

## M6 — Windows 体验与阅读质量（当前）

M6 的详细计划、缺陷证据和验收标准见 [M6 实施计划](m6-implementation-plan.md)。

- M6.0：修复设置入口、书源导入文件选择、外部 JSON 兼容、图标/字体基础和阅读基础排版设置。
- M6.1：建立安全的书源格式识别与 Legado 3.0 安全子集适配。
- M6.2：将 TXT/EPUB 从纯文本章节升级为安全内容块。
- M6.3：完善字体、背景、版心、段落和分页设置。
- M6.4：拆分页面组件并重做首页、书架和空状态体验。
- M6 每个切片必须保留合成夹具、Rust 测试、前端契约检查和 Windows 回归证据。

## M7 — 发布

完成签名安装包、版本策略、回归测试、隐私说明和首个可供公众试用的预览版。
