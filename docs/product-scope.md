# 产品范围

## 产品定位

Open Reader Desktop 是一款 Windows 优先、开源、可扩展的桌面阅读器。先解决本地内容阅读体验和用户自有书源管理，再扩展同步、朗读与自动更新。

## MVP 目标

1. 打开并阅读本地 TXT、EPUB。
2. 维护书架、阅读进度、最近阅读记录。
3. 提供可导入、校验、调试的书源配置。
4. 完成搜索、书籍详情、目录和正文获取链路。
5. 支持离线缓存和基础排版设置。

## 明确不做（MVP）

- 不内置未经授权的版权书源或书籍。
- 不绕过付费墙、登录限制、验证码、DRM 或访问控制。
- 暂不承诺完整兼容所有 Legado/阅读 JSON 扩展语法。
- 暂不支持 PDF 排版、漫画、音频和云端多端同步。
- 书源脚本默认不能访问任意本机文件、进程或系统命令。

## MVP 验收标准

- 新用户可在 Windows 上安装、导入一本本地书并从上次位置继续阅读。
- 用户可导入一份书源，看到校验错误位置，并完成授权/公开测试站点的搜索到正文流程。
- 断网后，已缓存的书籍和章节仍可阅读。
- 书源执行失败时能显示可诊断的请求、解析和脚本错误。
