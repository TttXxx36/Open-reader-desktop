# 产品范围

## 产品定位

Open Reader Desktop 是一款 Windows 优先、开源、可扩展的桌面阅读器。先解决本地内容阅读体验和用户自有书源管理，再扩展同步、发现、朗读与多媒体能力。

## MVP 目标

1. 打开并阅读本地 TXT、EPUB。
2. 维护书架、阅读进度、最近阅读记录。
3. 提供可导入、校验、预览、调试的书源配置。
4. 完成授权/公开测试源的搜索、书籍详情、目录和正文链路。
5. 支持离线缓存、基础排版、主题、字体和键盘操作。
6. 通过 GitHub Actions 生成 Windows 安装版、便携版和校验清单。

## 兼容策略

书源能力按三档管理：

- **可执行**：当前已验证的 HTTP、CSS/JSoup、正则、JSONPath 安全子集。
- **可导入但不执行**：已识别的 XPath、JavaScript、认证态或未实现扩展，预览中逐项说明原因。
- **明确拒绝**：危险脚本、敏感认证头、越权访问、音频书源和未定义协议。

目标不是复制 Android 端全部实现，而是逐层补齐数据模型、规则执行和安全边界；每一层都必须有夹具、错误案例、配额和兼容性矩阵记录。

## 许可证与书源政策

- 原创代码与文档采用 MIT License；第三方依赖、素材和贡献内容保留原许可证与归属。
- 只处理用户自有、已授权、公开测试或公版内容；不内置未经授权的版权书源，不绕过登录、付费、验证码、DRM 或访问控制。
- 书源兼容按“可执行”“可导入但不执行”“明确拒绝”分层，详见 [ADR 0002](adr/0002-license-and-source-policy.md) 与 [书源兼容性矩阵](compatibility-matrix.md)。

## 明确不做（MVP）

- 不内置未经授权的版权书源或书籍。
- 不绕过付费墙、登录限制、验证码、DRM 或访问控制。
- 不承诺完整兼容所有 Legado/阅读 JSON 扩展语法。
- 暂不支持 PDF 排版、漫画、音频和云端多端同步。
- 书源脚本默认不能访问任意本机文件、进程或系统命令。
- 不在本地构建或安装 Windows 包；发布验证只走 GitHub Actions。

## MVP 验收标准

- 新用户可在 Windows Actions 产物上安装、导入一本本地书并从上次位置继续阅读。
- 用户可导入一份书源，看到校验错误位置和不支持能力，并在授权/公开测试站点完成搜索到正文流程。
- 断网后，已缓存的书籍和章节仍可阅读。
- 书源执行失败时能显示可诊断的请求、解析、缓存和安全错误。
- 安装版和便携版来自同一提交，SHA-256 清单可验证。

## 后续范围与依赖

- M7：书源元数据、分组/排序、分页/变量、调试快照；XPath/JavaScript 需要独立安全闸门。
- M8：EPUB/TXT 质量、MOBI/AZW 与 PDF 评估、漫画图片模型。
- M9：书架分组、标签、封面、历史、书签、笔记和搜索索引。
- M10：版本化备份、恢复和可选 WebDAV 冲突检测。
- M11：RSS/Atom/OPDS 订阅与发现页。
- M12：TTS、漫画和音频能力评估。
