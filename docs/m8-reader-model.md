# M8.5.4 PDF 与图片独立阅读模型契约

状态：评估切片（不引入解析器或渲染依赖）

M8.5.1/M8.5.2 已完成安全格式探测和有界元数据读取；M8.5.4 先定义内部阅读模型，避免把 PDF 页和漫画图片错误地压进文本章节字段。完成本契约不代表格式已经可以导入。

## 目标与非目标

目标：

- 为 PDF、单图和图片序列定义可迁移、可缓存、可恢复的阅读对象。
- 把渲染、搜索、目录、页码/图片序号和阅读方向从文本章节模型中隔离。
- 明确内存、磁盘、解码、取消和错误恢复闸门，为后续依赖选型提供验收标准。

非目标：

- 不绕过 PDF 密码、DRM、访问控制或受保护文档。
- 不在本切片内引入 PDF 解析器、图片解码器或平台安装依赖。
- 不把 PDF 转成普通 TXT，也不把图片 OCR 结果当作原始正文。

## 统一阅读对象

后端向前端提供只读的 ReaderDocumentEnvelope：

- kind：text、pdf 或 image。
- source_id：本地书籍 ID；不把原始路径暴露给前端。
- title、author、cover：可选展示元数据。
- location：格式专属定位，必须可序列化并可恢复。
- capabilities：render、search、outline、zoom、spread、direction 等布尔能力。
- warnings：可操作的、脱敏的格式或资源提示。

文本仍使用现有章节/ContentDocument；PDF 和图片只能通过自己的 location 与页面数据访问。

## PDF 模型

PDF 文档至少包含：

- page_count：受上限约束的页数。
- pages：按需加载的页句柄，不一次性把所有页面位图放入前端状态。
- page_size：每页宽高和旋转信息；异常值只能作为未知。
- outline：可选的标题、页码和子节点；目标页超界时跳过并保留提示。
- text_layer：searchable、not_available 或 denied；搜索结果必须带页码和字符范围。
- location：page_index（从 0 开始）与可选的 zoom、scroll_offset。

渲染策略必须支持取消、单页失败隔离和重新加载。加密或受保护 PDF 只返回 denied，不尝试猜测密码或解除保护。

## 图片/漫画模型

图片文档至少包含：

- pages：顺序、MIME、宽高和本地资源句柄；资源按页/按需解码。
- direction：ltr、rtl 或 vertical。
- spread：single、double 或 long_strip；默认 single。
- location：page_index、zoom、pan_x、pan_y。
- cache_key：内容摘要与变换参数组合，不包含绝对路径或敏感信息。
- warnings：损坏页、超尺寸、解码失败和缓存淘汰原因。

双页模式只在相邻页方向一致时启用；封面是否单独显示由设置决定。Web URL、data URL 和 EPUB 外链图片不能直接进入该模型。

## 资源与缓存闸门

- 文件入口继续遵守 64 MiB 默认上限；未来若允许大型 PDF，必须另设格式配额并有 CI 基线。
- 图片尺寸继续受 100,000×100,000 探测上限约束；解码阶段还要限制像素总量、单页内存和并发页数。
- 缓存采用磁盘 LRU，键由书籍 ID、页面索引、缩放/旋转/主题和内容摘要组成；缓存写入必须原子替换。
- 页面渲染失败不得删除书籍或阅读进度；只标记当前页失败并允许重试/跳过。
- 前端只保留当前页、相邻预加载页和轻量缩略图，禁止把整本 PDF/漫画展开到 Vue 状态。

## 依赖采用闸门

在引入任何 PDF/图片依赖前，必须同时满足：

1. 许可证与再分发条款适用于公开 Windows 安装包和便携包。
2. Windows、Linux CI 均能在无本地安装步骤的情况下复现构建。
3. 解析/解码支持取消、资源上限、损坏输入恢复和受保护内容拒绝。
4. 依赖不会默认联网、执行脚本或写入用户范围以外的文件。
5. 1/16/64 MiB（或格式专属）夹具具备首屏、翻页、峰值 RSS 和缓存命中基线。

未满足闸门前，MOBI/AZW、PDF 和图片继续保持只读探测。

## 验收夹具

后续实现必须补充：

- PDF：最小有效文件、损坏 xref、空目录、超页数、受保护文件、单页渲染失败。
- 图片：PNG/JPEG/GIF/WebP 各一张，错误 MIME、零尺寸、超尺寸、损坏尾部和多页顺序。
- UI：探测结果、只读提示、页码/图片序号恢复、缩放/双页/方向设置和失败重试。
- CI：前端类型检查、Rust fmt/check/test、Windows 编译/采样；不在本地构建或安装。

## 当前决定

M8.5.4 当前只冻结模型和采用闸门，不启用 PDF/图片导入。下一步先做依赖许可证与 Windows 渲染路径评估；评估通过后再实现最小 PDF 单页渲染或图片序列阅读器，并保持与文本章节完全隔离。
